# Premium Portfolio Redesign — Design Direction

## Three possible approaches

### Approach A — The Masterwork Index
**Very Brief Intro:** A post-digital editorial portfolio that feels like a private studio catalogue: calm, precise, and intensely confident. Sculptural 3D objects act as proof of craft rather than visual noise.

**Probability:** 0.07

### Approach B — The Signal Room
**Very Brief Intro:** A low-light command-centre aesthetic where case studies read like live systems and dense technical details are surfaced through an animated interface language.

**Probability:** 0.04

### Approach C — The Kinetic Folio
**Very Brief Intro:** A gallery-inspired visual identity built from oversized typography, playful physical motion, and tactile cards that transform as visitors explore projects.

**Probability:** 0.09

---

## Chosen approach — The Masterwork Index

### Design Movement
**Post-digital editorial design** influenced by contemporary architecture monographs, Swiss grid discipline, and high-end product visualisation. The site should feel like an experienced builder presenting a curated body of work to a discerning client.

### Core Principles
1. **Evidence over decoration:** Every visual device must reinforce capability, clarity, or conversion.
2. **Sculptural restraint:** Use dimensional forms, deep shadows, and layered planes sparingly so the 3D treatment feels considered.
3. **Editorial rhythm:** Combine oversized display statements with small technical annotations and generous negative space.
4. **Visible craft:** Details such as refined hover states, tactile controls, and well-composed project framing should imply mastery before the visitor reads a full paragraph.

### Color Philosophy
The base is a near-black graphite field that gives the content gallery-level focus. A mineral cream softens long-form reading and a singular **signal vermilion** carries urgency, direction, and memorable brand ownership. Cool steel-blue reflections create depth in 3D objects without drifting into generic neon.

### Layout Paradigm
The page follows an **offset editorial spine** instead of a centered card grid. Large section markers sit in a narrow left rail while the main content creates varied horizontal moments: a split hero, an angled expertise inventory, horizontal project frames, and a final client invitation. This makes scrolling feel like moving through a considered portfolio book.

### Signature Elements
1. A mouse-responsive **3D craft prism** in the hero, built from layered planes and a generated sculptural visual.
2. Vermilion **coordinate tags** that label expertise, availability, and project discipline.
3. A fine architectural **rule system** with lightweight grid lines, deliberate cut-outs, and technical microcopy.

### Interaction Philosophy
Interaction should feel direct and material. Project cards tilt only slightly, controls compress on press, and the expertise prism responds to pointer movement without requiring the visitor to learn an interface. Every client-facing action has one clear outcome: explore work, inspect capabilities, or start a conversation.

### Animation
Use a fast custom ease-out for interface transitions, typically 160–260ms. The hero prism may drift slowly and tilt with pointer position; it becomes static when reduced motion is requested. Section reveals should use opacity plus short vertical translation, with 50ms stagger intervals. Avoid continuous decorative motion outside the hero and refrain from bouncing, spinning, or full-screen particle effects.

### Typography System
**Space Grotesk** carries display typography with weight contrast between 500 and 700. **DM Mono** handles navigation, labels, stats, and technical annotations. Headlines use compact line-height and deliberate line breaks; body text stays open and readable at 16–18px. The pairing balances expressive authority with technical credibility.

### Brand Essence
**A multidisciplinary web specialist who turns complex digital ideas into clear, high-performing client experiences.**

Personality adjectives: **precise, inventive, dependable**.

### Brand Voice
Headlines should be assertive, concrete, and outcome-oriented. CTAs should sound like an invitation to make a project sharper, not generic marketing filler.

Example headline: “Digital experiences with enough craft to earn attention.”

Example CTA: “Bring the difficult brief.”

### Wordmark & Logo
Use a bold, abstract **K/M folded prism**: three offset planes that suggest an initial, a perspective grid, and an engineered object. The mark appears as a solid symbol—never as a default text treatment—and is paired with a tightly tracked wordmark.

### Signature Brand Color
**Signal Vermilion — #FF4D2E.**

## Style Decisions

- Project visual framing must function as evidence: each case study includes a distinct product-screen crop sourced from the live project, paired with its own workflow annotation.
- The folded K/M prism is constructed from offset planes around the generated symbol so it reads as an engineered mark rather than a generic play icon.
- Italics are reserved for the final contact invitation; the primary hierarchy comes from Space Grotesk scale, line breaks, and mono annotations.
