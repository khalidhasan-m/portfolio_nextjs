# Portfolio Follow-ups Requiring Your Input

The portfolio upgrade now includes documented case studies, project evidence, live links, a refined contact path, mobile editorial structure, and search/share metadata. The items below are intentionally not fabricated because they depend on real results or account ownership.

## Verified outcome evidence

When available, provide real, attributable project details for RouteForm, SignalDesk, PawfectMatch, or client work. Useful evidence includes launch dates, measured performance changes, adoption or engagement numbers, accessibility audit results, before-and-after screenshots, and written permission to quote a real client or collaborator. These can be added to the case studies without inventing testimonials, ratings, or outcome claims.

## Custom domain and canonical URL

When you own or choose a domain, connect it in the project settings and share the chosen URL. The portfolio can then add a canonical tag, absolute Open Graph URL, absolute social image URL, and a sitemap that all point to the real public domain.

## Scheduling link

If you use a real booking service, provide the public scheduling URL. A concise “Book a short call” path can then be added beside the contact form. No placeholder booking destination has been added.
